# Tic Tac Toe

A modern, interactive tic tac toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- 🎮 **Two Game Modes**
  - Player vs Player: Play against a friend
  - Player vs AI: Challenge the computer

- 🤖 **AI with Difficulty Levels**
  - Easy: Random moves
  - Medium: Balanced gameplay
  - Hard: Unbeatable AI (uses minimax algorithm)

- 📊 **Score Tracking**
  - Track wins and draws across multiple games
  - Reset scores anytime

- 🎨 **Modern UI**
  - Clean, responsive design
  - Works on desktop and mobile
  - Smooth animations and transitions

## How to Play

1. Open `index.html` in your web browser
2. Select your game mode (Player vs Player or Player vs AI)
3. If playing vs AI, choose the difficulty level
4. Click "Start Game"
5. Click cells to make your move
6. Use "New Game" to play again without resetting scores
7. Use "Change Mode" to switch game types

## Getting Started

Simply open the `index.html` file in any modern web browser. No installation or build process required!
